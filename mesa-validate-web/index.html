MESA Validate

Human-in-the-Loop Validation Tool

Welcome to MESA Validate (Web Edition)

MESA Validate is a human-in-the-loop validation tool for LLM-extracted structured data. This is a fully self-contained web version -- no Python or server required. Just open this file in your browser.

How It Works

  1. Sessions tab -- Create a new validation session by selecting a schema, choosing fields to validate, and loading prediction JSON files from your computer.
  2. Validate tab -- Review each document side-by-side with LLM extractions. Mark each field as correct or incorrect using the validation controls.
  3. Analysis tab -- View aggregate metrics (precision, recall, F1, accuracy) across all validated documents. Export results as CSV.

Prediction File Format

Each prediction JSON file should have:

{ "content": "The original document text...", "output": { // LLM extraction result matching the schema } }

Data Storage

All session data and validation progress is stored locally in your browser using IndexedDB. Nothing is sent to any server. You can export and import sessions to back up your work or share with colleagues.
